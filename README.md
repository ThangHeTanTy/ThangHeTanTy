### 🔍 [Hardware Inspector](https://github.com/ThangHeTanTy/HardwareInspector)

Công cụ desktop thẩm định phần cứng laptop/PC **đã qua sử dụng** — trả lời câu hỏi *"cái máy này có đáng tin không?"*.

- Chấm điểm từng linh kiện (CPU, GPU, RAM, ổ cứng, pin, màn hình, bo mạch) theo thang 0-100: giờ chạy, % sức khoẻ, nhiệt độ min/avg/max
- Đọc trực tiếp **S.M.A.R.T./NVMe**, **EDID**, **SMBIOS**, bảng **ACPI**, biến **UEFI** qua P/Invoke — tự parse, không qua phần mềm trung gian
- 8 phép kiểm tra **BIOS bị can thiệp**: Secure Boot, WPBT, MSDM/SLIC, quét phân vùng EFI (SHA-256), TPM, VBS/HVCI…
- **Đối chiếu chéo** tuổi pin / ổ cứng / tấm nền / BIOS để phát hiện máy bị "làm đẹp"
- Stress test GPU bằng **compute shader Direct3D 11** có kiểm tra kết quả từng bit, test VRAM kiểu MemTest, test điểm chết màn hình
- Xuất biên bản **HTML / JSON**

### 🤡 [HeDeck](https://github.com/ThangHeTanTy/HeDeck)

Biến **điện thoại Android thành bàn điều khiển (Stream Deck) cho laptop Windows** — chạm một ô là ứng dụng trên máy tính mở lên và nhảy ra trước.

- Mở / chuyển / thu nhỏ / tắt ứng dụng, chọn đúng từng cửa sổ như taskbar Windows
- Ô **macro** phím tắt, ô **chế độ** mở-đóng nhiều app một lần, ô hai trạng thái
- **Âm lượng riêng từng app**, thanh điều khiển nhạc, 113 icon vector, bố cục 5×2 / 5×3 nhiều trang
- Tự tìm game từ **Riot, Steam, Epic**; bật máy từ xa bằng **Wake-on-LAN**, khoá / ngủ / tắt máy
- Bảo mật 3 tầng: chỉ mạng nội bộ, chặn IP dò mã, ghép cặp bằng chữ ký **Ed25519**
- Kiến trúc: app **Flutter** ⇄ WebSocket ⇄ **agent Python** chạy nền trên Windows, tự dò địa chỉ bằng mDNS

### 📧 [HotMailVerNew (SuperStarHotmail)](https://github.com/ThangHeTanTy/HotMailVerNew) <sub>🔒 private</sub>

Phần mềm desktop **quản lý số lượng lớn tài khoản Hotmail/Outlook**.

- Quản lý tài khoản theo thư mục, lọc trùng, cập nhật hàng loạt, sao chép theo định dạng tuỳ chỉnh
- Đọc hộp thư qua **IMAP / POP3** với xác thực **OAuth2**, kiểm tra email khôi phục
- Tự động hoá trình duyệt bằng **Selenium** (đăng ký, mở khoá, khôi phục tài khoản) chạy đa luồng, xếp cửa sổ dạng lưới
- Quản lý & kiểm tra **proxy** (Tinsoft, XProxy), cấu hình user-agent, profile trình duyệt
- Lưu trữ **SQLite**, mã hoá dữ liệu nhạy cảm bằng **AES**, tự cập nhật phiên bản (AutoUpdater.NET)
